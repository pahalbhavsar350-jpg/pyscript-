# Tuition ERP

Public-hosting-ready Flask tuition ERP.

Features: dashboard, clickable ERP cards, student records, monthly fee ledger, payment collection, receipts, expenses, PostgreSQL support, responsive mobile UI.

Local: run `run.bat`, then open http://127.0.0.1:5000.

Render: use render.yaml. Set ADMIN_PASSWORD in Render. The public service gets an onrender.com URL.
